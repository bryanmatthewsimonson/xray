## 2026-10-17 — "Content changed since your last capture" now needs a word to change, and shows which

**Tags:** bug, reader, design

Field report: the reader's stealth-edit banner fired often on pages
nobody had edited. Cause: the banner fired on any canonical-hash
mismatch, and that hash is the audit anchor (Phase 13.4) — byte-exact
over the assembled markdown on purpose. Extraction noise moves it: a
relative timestamp ("3 hours ago"), engagement counts, an image CDN
URL that rotates size/format/signature between loads, tracking query
strings on links, turndown escapes, curly-vs-straight quotes. The hash
was right to move; the banner's claim ("the page was edited") was not.

Fix (`src/reader/recapture-diff.js`): the hash is untouched. When it
mismatches, the reader diffs the archived row's body against the open
one under a comparison-only normalization (images → alt text, URL
query/fragment dropped, escapes/quotes/dashes/whitespace folded,
relative times and engagement counts removed). No word changed → no
banner. Otherwise the banner says what changed ("2 paragraphs edited,
1 added") and a "Show changes" toggle opens a paragraph-aligned diff
with word-level marks and collapsed context. The prior body is
assembled the way the reader assembles the current one (markdown for
markdown-canonical types), so a PDF's derived HTML never false-flags.
If the diff cannot be computed the banner still shows, without detail.

Second-guessable calls:
- Suppressing the banner hides nothing (CONSTITUTION Art. 3): the
  archive still snapshots the displaced version into `priorVersions`
  on every hash move, noise or not, and the audit panel's prior-version
  note still keys on hashes.
- Image `src` changes count as noise. An image swapped under the same
  alt text no longer raises the banner. Accepted: CDN path churn was a
  leading false-positive source, and alt text is what the body says.
- Link targets still count, minus query and fragment, so a changed
  source link is still an edit.
- A changed middle above 4M paragraph-pair cells (a re-chunked long
  transcript) reports counts only, so it never hangs the reader.

The banner moved out of `reader/index.js`, and its ceiling went down
by the lines removed (8297 → 8263).
