## Verdict

A non-technical researcher's first hour with X-Ray does not exist yet, and a month after ROAD_TO_1_0 said so (B7, B12, B13) the only first-hour item that landed is "Options opens on Signing when no identity exists" (`src/options/index.js:1858`). Everything else is still true today: no install channel (`package.json:38-43` still ships tests/, docs/ and source maps in the zip; `CONTRIBUTING.md:172-174` still calls the store a manual afterthought); Publish is one click into a 1,600-line loop whose "Also publishing your judgments…" disclosures are 4-second toasts fired *after* the events are on the wire (`src/reader/index.js:8119`, `:6653`, `:6891`, `:6995`, `:7171`); `onInstalled` registers context menus and nothing else (`src/background/index.js:368`); the three user docs still tell the newcomer to click **Generate new key**, a button that has been **New identity…** / **Generate & switch** since before August (`README.md:265`, `docs/USER_GUIDE.md:111` vs `src/options/options.html:105,117`); and the five extension shells contain zero links to any user documentation (the one `docs/` mention in a shell is `options.html:375`, pointing a researcher at a Node CLI directory).

Counted, the first hour meets **6 surfaces** (reader, Settings, Entities side panel, Archive/portal, Network, plus the reader's PDF mode and a GitHub tab called "Capture tips"), **11 entry points**, **~105 static buttons** (Settings alone: 41 buttons, 41 inputs, 4 selects; reader header + bars: 20; side panel: 14 list-level + 13 per-entity), **13 reader modals**, **18 Settings → Advanced subsections**, **20 feature flags** (19 in `FLAGS_DEFAULTS` + `extractionAnalysisPublishing`), and **~55 distinct user-facing nouns**, of which a researcher needs about a dozen. The consolidation debt is specific and countable: the entity has **four** destinations (side-panel compact dossier, portal spokes view, portal full dossier, portal "Entity corpus" — `sidepanel/index.js:1832-1842`, `portal/entity-view.js:70-80`, `entity-dossier-view.js:1`, `entity-corpus-view.js:1`); import/export has **20 verbs across 4 surfaces**; the *one* cached LLM article pass has **four names** ("✨ Suggest…", "Pre-analyze…", "Analyze each imported page", the map stage of "Analyze corpus…") beside five more AI verbs; transcription has two transports, three entry points and an engine picker; and the same five "open a surface" actions carry two naming vocabularies (`xray:open-portal` menu ids at `background/index.js:76-82` vs `xray:openPortal` messages at `:456-471`).

The good news is equally specific. The kill list has real momentum (6 of 15 done in one day when the maintainer said "kill them all"), the tree is *not* rotten with dead modules (exactly one orphan module in 247; every flag is read), the capture pipeline and the select-text popover are the quality bar every lens names, and the pieces of a first hour already exist in fragments — a first-run banner, a default-to-Signing rule, disclosure paragraphs on every publish toggle, a Playwright harness that can shoot the guide's screenshots. What is missing is the *ordering* and the *collapse*: one front door, one path through it, and one home per concept. That is a consolidation job, not a rewrite, and most of it is subtraction.

### NEWC-01 · There is no way for the target user to install or keep X-Ray — harm 5 · DEFECT · Effort L · B7 (open)
- **Evidence:** `package.json:38-43` `webExt.ignoreFiles` = `["companion","companion/**"]` only — tests/, docs/ (64 entries incl.
